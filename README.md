## 📂 هيكل المشروع

تم بناء المشروع باستخدام:
- **Next.js 15**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** & **GSAP**
- **Supabase** (قاعدة بيانات + تخزين + مصادقة)

## 🚀 تشغيل المشروع محلياً

1. **تثبيت المكتبات**
```bash
npm install
```

2. **إعداد البيئة**
   - انسخ ملف `.env.example` وسمه `.env`
   - ضع بيانات Supabase الخاصة بك بداخله

3. **تشغيل السيرفر**
```bash
npm run dev
```

## ⚙️ إعداد Supabase

1. أنشئ مشروع جديد على Supabase
2. قم بتنفيذ الكود الموجود في `supabase-schema.sql` في SQL Editor
3. أنشئ باكيت (Bucket) باسم `projects-media` للتخزين
4. قم بإنشاء مستخدم (Admin) عبر Supabase Auth

## 🎨 أعمالي المضافة
